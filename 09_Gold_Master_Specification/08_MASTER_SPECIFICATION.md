# Worksheet Wonder: Gold Master Publishing Specification

## Overview
This directory (`09_Gold_Master_Specification`) contains the absolute, immutable rules for generating Worksheet Wonder commercial products. These standards ensure that whether the Node.js engine generates an Alphabet worksheet today, or a Math worksheet 5 years from now, the Worksheet Wonder brand remains perfectly cohesive, premium, and educationally sound.

## The Specifications
No developer, designer, or educational consultant is permitted to modify the HTML Framework, CSS Framework, Illustration Library, or Content Database without first ensuring compliance with these 7 pillars:

1.  **[01. Page Blueprint Specification](./01_PAGE_BLUEPRINT.md)**
    *   Defines the strict A4 grid, the 15mm margins, the 12-column math, and the locked typography sizes.
2.  **[02. Activity Flow Specification](./02_ACTIVITY_FLOW.md)**
    *   Defines the rigid 11-step chronological pedagogical sequence every kindergarten worksheet must follow.
3.  **[03. Handwriting Standard Specification](./03_HANDWRITING_STANDARD.md)**
    *   Defines the mathematical rendering of the 3-line educational guides (Top, Midline, Baseline) and starting dot placements.
4.  **[04. Illustration Standard Specification](./04_ILLUSTRATION_STANDARD.md)**
    *   Defines the 3.5px SVG strokes, the flat CMYK colors, and the "chibi-style" character proportions.
5.  **[05. Commercial Print Standard Specification](./05_PRINT_STANDARD.md)**
    *   Defines the 300 DPI, 0-bleed, CMYK-safe PDF rendering requirements.
6.  **[06. Content Standard Specification](./06_CONTENT_STANDARD.md)**
    *   Defines the phonics accuracy, syllable limits, and curriculum tagging requirements for the JSON database.
7.  **[07. Quality Assurance Checklist](./07_QUALITY_CHECKLIST.md)**
    *   The final 18-point Pass/Fail rubric that every generated PDF must clear before commercial distribution.
