# 05. Commercial Print Standard Specification

Every worksheet generated by the Node.js engine must conform to these strict physical output parameters to be accepted by commercial printing presses (e.g., KDP, IngramSpark, offset lithography).

## 1. Document Format
*   **Target Output:** PDF/X-1a:2001 or standard high-resolution PDF.
*   **Resolution:** Minimum 300 DPI (Dots Per Inch).
*   **Trim Size:** Exact A4 (210 mm x 297 mm).
*   **Bleed:** 0 mm. All artwork and backgrounds must be contained within the 15 mm Safe Zone. No edge-to-edge printing is required for this curriculum layout.

## 2. Color Space
*   **Profile:** CMYK (Cyan, Magenta, Yellow, Key/Black).
*   **Screen to Print Conversion:** The HTML Engine parses hex codes. The PDF exporter must strictly enforce the `print-color-adjust: exact;` CSS rule to prevent browser-engine color washing.
*   **Rich Black:** Do not use Rich Black for typography. All standard text (tracing lines, instructions) must be mapped to Standard Black (C:0 M:0 Y:0 K:100) or our Dark Slate equivalent (`#1E293B`) to avoid registration errors (ghosting) on high-speed presses.

## 3. PDF Generator Engine Configuration
When Puppeteer (or the selected Chromium exporter) processes the HTML:
*   `printBackground` MUST be true.
*   `preferCSSPageSize` MUST be true.
*   All digital margins injected by the browser (headers/footers with dates or URLs) MUST be disabled (`displayHeaderFooter: false`).
*   All web-only interactive elements (e.g., hover states, animations, print buttons) must be suppressed using `@media print { .hidden-print { display: none; } }`.
