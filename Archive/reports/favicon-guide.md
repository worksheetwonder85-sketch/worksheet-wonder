# Favicon Implementation Guide for Worksheet Wonder

Since physical binary image files (.ico, .png) cannot be dynamically generated by the current system without an image library, you will need to manually place the favicon graphics.

Please follow these exact instructions to properly install the favicons across the Worksheet Wonder website.

## 1. Required Favicon Files
You need to generate or obtain the following image files (using your existing logo):

*   `favicon.ico` (Standard multi-resolution icon file, fallback for older browsers)
*   `favicon-16x16.png` (Standard low-res PNG icon)
*   `favicon-32x32.png` (Standard high-res PNG icon)
*   `apple-touch-icon.png` (Used when a user saves the site to their iOS home screen. **Recommended size: 180x180 pixels**)

## 2. Folder Location
Place all four of the generated image files directly into your existing icons directory:
`assets/images/icons/`

## 3. Web App Manifest
I have already created the `site.webmanifest` file in the root directory for you. This file tells Android Chrome browsers how to display your app on the home screen.

## 4. HTML Tags to Include
To activate these icons, you must paste the following block of code into the `<head>` section of **every HTML file** in the project (index.html, shop.html, blog.html, etc.), just below the `<title>` tag:

```html
<!-- Favicons -->
<link rel="icon" type="image/x-icon" href="assets/images/icons/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="assets/images/icons/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="assets/images/icons/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="assets/images/icons/apple-touch-icon.png">
<link rel="manifest" href="site.webmanifest">
```

Once pasted, all modern browsers, mobile devices, and search engines will correctly display the Worksheet Wonder logo on tabs and bookmarks.
