# 🧩 Worksheet Wonder Activity System Specifications

This document establishes the standardized mechanics, pedagogical goals, visual layouts, and scoring criteria for all **12 Core Activity Modules** across Worksheet Wonder print products.

---

## 1. Tracing Activity Module
- **Purpose**: Build fine motor muscle memory, pencil grip control, and stroke order directional habits.
- **Layout**: Model letter in solid color + starting dot (●) + stroke directional arrows (→) + 3 rows of transparent dotted letters (`-webkit-text-stroke: 2px`).
- **Scaffold**: Row 1 (high guidance dots), Row 2 (medium spacing), Row 3 (independent tracing).
- **Target Age**: Ages 3–5.

## 2. Independent Writing Activity Module
- **Purpose**: Transition students from guided tracing to independent letter formation and line placement.
- **Layout**: Double-ruled handwriting baseline with dashed midline (`height: 10mm`, `border-bottom: 2px solid #2C3E50`, dashed center rule).
- **Scaffold**: Faded model letter at start of line as reference.
- **Target Age**: Ages 4–6.

## 3. Matching & Connecting Module
- **Purpose**: Build visual-spatial reasoning and associative sound-to-item mapping.
- **Layout**: Paired parallel columns (Left: Uppercase/Lowercase or Letters; Right: Illustrated Vocabulary Items).
- **Instruction**: "Draw a line to match each letter to its picture!".
- **Target Age**: Ages 4–6.

## 4. Beginning Sounds Activity Module
- **Purpose**: Develop phonemic awareness and initial phoneme-grapheme identification.
- **Layout**: 6 vector picture boxes (3 correct initial sound matches + 3 distractor pictures).
- **Scaffold**: Clear labels below each picture for vocabulary reinforcement.
- **Target Age**: Ages 4–6.

## 5. Circle Grid Activity Module
- **Purpose**: Visual discrimination and letter identification among confusable letter pairs (e.g. B/D/P/Q or C/G/O).
- **Layout**: 6×5 circular cell matrix (30 total letters; ~12 target letter cells).
- **Instruction**: "Circle every target letter you can find!".
- **Target Age**: Ages 4–6.

## 6. Find & Search Matrix Module
- **Purpose**: Systematic visual scanning (left-to-right, top-to-bottom) for reading readiness.
- **Layout**: 5×5 rectangular grid containing exactly 5 hidden target letters.
- **Scaffold**: Checkmark summary bar at bottom (`Find 5 letters ✓ ✓ ✓ ✓ ✓`).
- **Target Age**: Ages 4–6.

## 7. Cut & Paste Activity Module
- **Purpose**: Bilateral coordination, scissor skills, and tactile categorization.
- **Layout**: Target pasting boxes on upper sheet + dotted scissor line cut-out strip at bottom of page.
- **Target Age**: Ages 4–6.

## 8. Maze Activity Module
- **Purpose**: Spatial planning, problem-solving, and hand-eye coordination.
- **Layout**: Path matrix requiring student to follow target letter path from start (character) to finish (reward).
- **Target Age**: Ages 4–6.

## 9. Coloring & Fine Motor Module
- **Purpose**: Finger strength, spatial boundary awareness, and creative engagement.
- **Layout**: High-contrast vector outline illustrations (`fill="none"`, `stroke="#2C3E50"` `stroke-width="2.5px"`).
- **Target Age**: Ages 3–5.

## 10. Counting & Quantity Matching Module
- **Purpose**: Early math integration, 1-to-1 correspondence, and quantity recognition.
- **Layout**: Groups of vector illustrations paired with number tracing/writing boxes.
- **Target Age**: Ages 4–6.

## 11. Review Activity Module
- **Purpose**: Cumulative consolidation across multi-letter units (e.g. Letters A–G Review).
- **Layout**: Mixed multi-activity review sheets combining matching, sorting, and writing.
- **Target Age**: Ages 4–6.

## 12. Revision & Diagnostic Assessment Module
- **Purpose**: Teacher and parent evaluation of mastery milestones.
- **Layout**: Standardized test format with clear scoring boxes and rubrics.
- **Target Age**: Ages 4–6.
