# 🎨 Master SVG Vector Requirements Inventory (78 Vocabulary Assets + UI Icons)

This document contains the complete technical specification and manifest for every inline SVG vector graphic required in **"My First Alphabet Workbook"**.

---

## 1. Technical Standards for All SVG Assets
- **Format**: XML-compliant inline SVG `<svg viewBox="..." fill="none">`.
- **ViewBox Dimensions**: Vocabulary SVGs (`viewBox="0 0 80 65"`), Activity Picture Boxes (`viewBox="0 0 60 45"`).
- **Line Weights**: Outer outlines `1.5px` to `2.5px` (`#2C3E50` or `#333333`), internal details `1.0px`.
- **Color Fill Standards**: Clean pastel HSL fills with subtle gradients; white highlight overlays (`opacity="0.4"`).
- **No Bitmap Data**: Zero `<image>` tags, base64 data URIs, or external PNG links allowed.
