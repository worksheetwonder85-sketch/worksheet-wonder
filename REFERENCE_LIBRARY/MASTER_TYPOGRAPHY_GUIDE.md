# Master Typography Guide

## Primary Fonts
- Headers & Display: 'Fredoka', sans-serif (Google Fonts, weights: 500, 600, 700)
- Body & Instructions: 'Nunito', sans-serif (Google Fonts, weights: 400, 600, 700, 800)

## Scale & Sizing (Print Baseline)
- Brand Logo: 16pt Fredoka Bold
- Main Worksheet Title: 20pt - 22pt Fredoka Bold
- Panel Section Titles: 10pt - 11pt Fredoka Bold
- Activity Instructions: 7.5pt - 8.5pt Nunito Italic
- Display Model Letters: 62pt Fredoka Bold
- Tracing Letters: 32pt Fredoka (-webkit-text-stroke: 2px)
