# Master Spacing Guide

## Page Dimensions & Margins
- Page Size: A4 Portrait (210mm x 297mm)
- Outer Padding: Top 13mm, Right 12mm, Bottom 11mm, Left 12mm
- Inner Border Inset: Outer border at 5mm inset, Inner border at 7mm inset

## Grid Gaps
- Activity Grid Gap: 3mm to 4mm
- Panel Internal Padding: 2.5mm to 3mm
- User Bar Field Gap: 5mm
