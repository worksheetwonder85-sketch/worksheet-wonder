# Master Activity Library

## Taxonomy of Standard Activity Types
1. Meet the Letter / Subject: Large display focal element + vocabulary cards with SVG illustrations.
2. Tracing (Uppercase & Lowercase): Dotted guides with stroke directional arrows and starting dots.
3. Independent Writing: Double-ruled handwriting lines with dashed midline (e.g., 9mm line height).
4. Visual Discrimination / Circle Grid: Grid of mixed items for target identification.
5. Phonemic / Beginning Sounds: Picture boxes requiring sound-to-letter matching.
6. Search & Hunt Grid: Word search or letter grid matrix (e.g., 5x5 grid with hidden targets).
7. Matching & Connecting: Paired columns requiring line drawing connection.
8. Reward & Self-Assessment: Sticker circles, star ratings, and encouraging closing praise.
