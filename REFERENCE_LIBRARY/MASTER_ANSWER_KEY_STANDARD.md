# Master Answer Key Standard

## Design Standards for Answer Keys
1. Top Banner: Mandatory red banner (#C62828) reading "ANSWER KEY - For Teacher / Parent Use Only".
2. Answer Highlighting:
   - Correct selections circled in bright red (#E53935) or green (#4CAF50).
   - Correct beginning sounds marked with green checkmark badges.
   - Write-in sections populated with semi-transparent answer text (color: rgba(198,40,40,0.6)).
3. Scoring Box: Footer summary area for scoring (e.g. Score: __ / 30).
