# Master Color Guide

- Kindergarten: Soft Amber (#FF9800), Sky Blue (#64B5F6), Rose (#FF8A80)
- Grade 1: Emerald Green (#388E3C), Golden Yellow (#FFD54F)
- Grade 2: Royal Blue (#1565C0), Lavender (#B39DDB)
- Grade 3: Deep Orange (#E65100), Teal (#00796B)
- Grade 4: Indigo (#283593), Slate (#455A64)
- Grade 5: Crimson (#C62828), Dark Teal (#004D40)
