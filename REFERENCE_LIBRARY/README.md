# Worksheet Wonder -- Reference Library

## Purpose
Central repository for educational research, competitive analysis, design standards, and publishing documentation across Preschool through Grade 5.

## What Belongs Here
Master research guides, design specifications, grade and subject taxonomies, quality checklists, and analysis templates.

## Naming Convention
Folders: ALL_CAPS_WITH_UNDERSCORES or Numbered Prefixes. Master Docs: MASTER_DOCUMENT_NAME.md.

## Future Workflow
1. Conduct research -> 2. Perform analysis -> 3. Standardize design -> 4. Quality Audit -> 5. Final Publishing.

## Connection to Publishing Process
Serves as the single source of truth (SSOT) and foundational specification framework for generating all Worksheet Wonder educational resources.
