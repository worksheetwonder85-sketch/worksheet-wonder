# Master Teacher Guide Standard

## Structure for Teacher Guides
1. Curriculum Alignment: EYFS, Common Core, and ACARA mapping codes.
2. Guided Lesson Plan: 20-minute lesson structure (Hook -> Introduce -> Guided Tracing -> Independent -> Closure).
3. Differentiation Framework: Support (yellow highlight), On-Track, and Extension tasks.
4. Assessment Rubric: 4-point scale rubric (Exceeds, Meets, Approaching, Beginning) across all activities.
5. Classroom Management: Fine-motor warmups, portfolio management, and early finisher tasks.
