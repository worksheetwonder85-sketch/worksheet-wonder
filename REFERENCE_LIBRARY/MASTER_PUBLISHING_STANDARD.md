# Master Publishing Standard

## 1. File & Directory Conventions
- Every worksheet must reside in its designated grade/subject directory.
- File Naming: WW-[GRADE_CODE]-[SUBJECT_CODE]-[TOPIC_CODE]-[SEQ_ID].html (e.g. WW-KG-ENG-ALPHABET-001.html).

## 2. Technical Requirements
- HTML5 strict semantic structure.
- Embedded CSS @media print with -webkit-print-color-adjust: exact.
- Zero external bitmap image dependencies (all illustrations must be vector inline SVG).
- Dual border system: Outer 0.8mm solid #2C3E50, Inner 0.4mm dashed #2C3E50.

## 3. Mandatory Page Components
1. Header: Brand Logo, Grade Badge, Age Badge, Free/Premium Badge.
2. User Info Bar: Name, Date, Teacher fields with baseline rules.
3. Worksheet Title & Scaffold Block (Objective + Instruction).
4. Activity Grid (2-column or 1-column responsive flex grid).
5. Footer: Website URL, Page Number, Star Rating / Reward.
