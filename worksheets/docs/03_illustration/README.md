## Scope

The Illustration Bible (3 parts) defines:

- Illustration philosophy and emotional contract
- Child-friendly design laws (7 non-negotiable rules)
- Shape language theory and grammar
- Character proportion grid (8-unit head system)
- 9 approved facial expressions with technical specs
- 5-component eye anatomy system
- 6-type mouth library
- 4 hand types by age range
- 5-level line weight hierarchy
- Complete SVG coding standards
- Layer and file naming conventions
- B&W tonal system (5 tones)
- Master colour palette (primary, secondary, neutral, skin tones, hair)
- Accessibility (CVD, low vision, cognitive)
- Quality checklist and approval form

Every illustration — in every worksheet, cover, poster, certificate, sticker, and badge — must comply with this system.
