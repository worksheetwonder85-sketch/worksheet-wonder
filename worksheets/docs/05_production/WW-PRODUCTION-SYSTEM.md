# 1. PRODUCT LIFECYCLE

The Worksheet Wonder product lifecycle maps the progression of a resource from initial conceptualisation to a live, income-generating asset. No step may be bypassed. The process is gated at key milestones to ensure zero defect propagation.

## 1.1 Lifecycle Stages

```
   [01. Idea] ──────────────► [02. Curriculum Mapping] ─────► [03. Bundle Specification]
        │                                                           │
        ▼                                                           ▼
   [06. Teacher Guide] ◄──── [05. Worksheet Production] ◄──── [04. Illustration Briefing]
        │
        ▼
   [07. Parent Guide] ──────► [08. Answer Key Generation] ──► [09. Certificate & Trackers]
                                                                    │
                                                                    ▼
   [12. Listing SEO] ◄────── [11. Thumbnail & Mockups] ◄──── [10. Preview Generations]
        │
        ▼
   [13. Platform Uploads] ──► [14. Quality Assurance Gate] ─► [15. Active Release]
                                                                    │
                                                                    ▼
                                                             [16. Version Control]
```

## 1.2 Step-by-Step SOP

### Stage 01: Idea & Concept
*   **Action:** Identify market demand, search trends (TPT, Etsy, Google Trends), or curriculum gaps.
*   **Input:** Keyword analysis, competitor scans, user feedback.
*   **Process:** Draft a one-paragraph concept pitch containing target age, core topic, and unique selling proposition.
*   **Output:** Signed-off Concept Brief.
*   **Gatekeeper:** Publishing Director.

### Stage 02: Curriculum Mapping
*   **Action:** Align the concept to the Worksheet Wonder Master Curriculum ([WW-MC-001](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/02_Curriculum/WW-MASTER-CURRICULUM.md)).
*   **Input:** [WW-MC-001](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/02_Curriculum/WW-MASTER-CURRICULUM.md) standards.
*   **Process:** Identify specific Unit, Topic, Subtopic, and target Learning Outcomes. Determine the progression path (Easy → Medium → Hard).
*   **Output:** Curriculum Mapping Record.
*   **Gatekeeper:** Curriculum Director.

### Stage 03: Bundle Specification
*   **Action:** Design the bundle architecture and layout plan.
*   **Input:** Worksheet Wonder Design Bible ([WW-DB-001](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/01_Brand/WW-DESIGN-BIBLE.md)).
*   **Process:** Outline the 18 components, list each worksheet page with its specific instructional target, layout grid, and interactive elements.
*   **Output:** Bundle Specification Sheet.
*   **Gatekeeper:** Senior Educational Designer.

### Stage 04: Illustration Briefing
*   **Action:** Identify and plan all required visual assets.
*   **Input:** Illustration Bibles [WW-IB-001](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/03_Illustration/WW-ILLUSTRATION-BIBLE-PART-1.md), [WW-IB-002](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/03_Illustration/WW-ILLUSTRATION-BIBLE-PART-2.md), and [WW-IB-003](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/03_Illustration/WW-ILLUSTRATION-BIBLE-PART-3.md).
*   **Process:** Check the reusable asset library. For new assets, write precise SVG specifications (shapes, proportions, B&W tones, layer groups).
*   **Output:** Illustration Asset List & Illustrator Brief.
*   **Gatekeeper:** Senior Art Director.

### Stage 05: Worksheet Production
*   **Action:** Code and construct individual worksheet pages.
*   **Input:** Templates, style guides, SVGs, copy deck.
*   **Process:** Code pages in clean HTML/CSS with embedded vector graphics, maintaining exactly 40%+ white space and the dual-border system.
*   **Output:** Rendered HTML source files and individual page vector drafts.
*   **Gatekeeper:** Senior Designer.

### Stage 06: Teacher Guide
*   **Action:** Author pedagogical instructions for classroom educators.
*   **Input:** Master Curriculum standards, drafted worksheets.
*   **Process:** Detail warm-up activities, guided practice, scaffolding techniques, classroom grouping strategies, and assessment standards.
*   **Output:** Teacher Guide Page drafts.
*   **Gatekeeper:** Senior Educational Designer.

### Stage 07: Parent Guide
*   **Action:** Author family-friendly instruction guides for home learning.
*   **Input:** Drafted worksheets, parent communication tone guidelines.
*   **Process:** Translate educational jargon into simple terms; outline 5 quick home activities using common objects; supply dinner-table conversation prompts.
*   **Output:** Parent Guide Page drafts.
*   **Gatekeeper:** Senior Educational Designer.

### Stage 08: Answer Key Generation
*   **Action:** Produce complete, error-free answer pages.
*   **Input:** Final worksheet pages.
*   **Process:** Solve every problem independently. Overlay correct answers in designated red accent color (#E53935) on scaled thumbnails of the worksheet pages.
*   **Output:** Complete Answer Key pages.
*   **Gatekeeper:** Educational Reviewer.

### Stage 09: Certificate & Trackers
*   **Action:** Create student reward and tracking assets.
*   **Input:** Bundle theme, certificate templates ([WW-IB-003](file:///c:/Users/erpri/OneDrive/Desktop/worksheet%20wonder/worksheets/docs/03_Illustration/WW-ILLUSTRATION-BIBLE-PART-3.md) Category 21).
*   **Process:** Design matching Certificate of Completion, Child Progress Tracker, and printable Reward Sticker sheets.
*   **Output:** Reward Pack files.
*   **Gatekeeper:** Senior Art Director.

### Stage 10: Preview Generations
*   **Action:** Compile and export standard customer previews.
*   **Input:** All compiled PDF pages.
*   **Process:** Render all bundle pages at 300 DPI, apply the standard semi-transparent watermark, and select 8–12 representative pages to export as RGB PNGs.
*   **Output:** Watermarked preview images.
*   **Gatekeeper:** Publishing Director.

### Stage 11: Thumbnail & Mockups
*   **Action:** Create commercial packaging images.
*   **Input:** Bundle cover, selected previews, mockup templates.
*   **Process:** Place covers inside A4 device/paper mockup templates. Add text badges highlighting key metrics (e.g., "50 Pages", "Answer Key Included"). Ensure legibility at 100px width.
*   **Output:** Platform-optimized Thumbnails (TPT, Etsy, Amazon, Web).
*   **Gatekeeper:** Marketing Director.

### Stage 12: Listing SEO
*   **Action:** Write search-optimized listings.
*   **Input:** Competitor keyword research.
*   **Process:** Draft product title with primary keyword; write long-form description outlining educational value, page contents, outcomes, and license terms. Compile 13 tags.
*   **Output:** Listing Metadata Sheet (`[BUNDLE-ID]-SEO.md`).
*   **Gatekeeper:** Marketing Director.

### Stage 13: Platform Uploads
*   **Action:** Assemble listings on draft channels.
*   **Input:** Compiled PDF, thumbnails, previews, metadata sheet.
*   **Process:** Upload files to draft areas on TPT, Etsy, KDP, and Shopify. Set pricing tier and category tagging. Do not publish.
*   **Output:** Platform listing drafts.
*   **Gatekeeper:** Website Manager.

### Stage 14: Quality Assurance Gate
*   **Action:** Execute comprehensive QA check.
*   **Input:** Live listing drafts and final downloaded bundle PDFs.
*   **Process:** Run the 10-point Quality Assurance checklist (see [Section 5](#5-quality-assurance)). Resolve any flagged defect.
*   **Output:** Signed-off QA Report.
*   **Gatekeeper:** QA Lead.

### Stage 15: Active Release
*   **Action:** Launch the product publicly.
*   **Input:** Signed QA Report, approved drafts.
*   **Process:** Change listing status from "Draft" to "Active/Public". Verify links and download delivery workflows. Run the product release marketing flow.
*   **Output:** Live product listings.
*   **Gatekeeper:** Publishing Director.

### Stage 16: Version Control
*   **Action:** Monitor feedback and execute updates.
*   **Input:** Customer reviews, errata logs, curriculum updates.
*   **Process:** Log modifications, increment semantic version, update version logs, distribute updated PDFs to buyers, and archive retired versions.
*   **Output:** Version logs and archived files.
*   **Gatekeeper:** Operations Manager.

# 2. BUNDLE ARCHITECTURE

All Worksheet Wonder bundles must follow a standard structural sequence. This consistency guarantees a premium user experience.

## 2.1 The Standard 18-Component Order

Every export PDF bundle must contain these 18 components in the exact order specified:

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 01. Cover Page ─────────────────────────────────────────────────────────► │
│ 02. Welcome & Credits ──────────────────────────────────────────────────► │
│ 03. Teacher Guide (2-4 pages) ──────────────────────────────────────────► │
│ 04. Parent Guide (1-2 pages) ───────────────────────────────────────────► │
│ 05. Detailed Learning Outcomes ─────────────────────────────────────────► │
│ 06. Skills Checklist (3-column) ────────────────────────────────────────► │
│ 07. Materials Required List ────────────────────────────────────────────► │
│ 08. Core Worksheets (Foundation → Developing → Mastery) ────────────────► │
│ 09. Creative Challenge Activity (Bloom's Level 5/6) ────────────────────► │
│ 10. Cumulative Assessment ──────────────────────────────────────────────► │
│ 11. Answer Key (Thumbnails with overlay answers) ───────────────────────► │
│ 12. Printable Certificate of Completion (Landscape) ───────────────────► │
│ 13. Student Progress Tracker (Self-rating stars) ───────────────────────► │
│ 14. Optimal Printing Guide (Home & School settings) ────────────────────► │
│ 15. Copyright Page ─────────────────────────────────────────────────────► │
│ 16. Single-Classroom / Personal License terms ──────────────────────────► │
│ 17. Version History Log ────────────────────────────────────────────────► │
│ 18. Internal Quality Sign-off (Not included in customer distribution) ────│
└───────────────────────────────────────────────────────────────────────────┘
```

## 2.2 Component Standards

1.  **Cover Page:** Must use the large Fredoka One title font, a colorful thematic SVG illustration, the official age/grade badges, and a clean dual border. No white margins on the cover page (full bleed design).
2.  **Welcome & Credits:** Introduces the brand voice and credits artists/authors. Contains a link to the Worksheet Wonder homepage.
3.  **Teacher Guide:** Pedagogical instructions, warm-up games, physical activity ideas, differentiation instructions (for below-level, on-level, and above-level students), and academic vocabulary terms.
4.  **Parent Guide:** Plain-language translation of learning objectives, everyday home activities to reinforce concepts, and vocabulary conversation prompts.
5.  **Learning Outcomes:** Written as child-friendly "I Can" statements with large check-boxes for tracking.
6.  **Skills Checklist:** A 3-column table showing specific skills, status columns (Not Yet, Developing, Mastered), and notes.
7.  **Materials Required:** Explicit checklist of pencils, colors, scissors, glue, or specialized manipulatives.
8.  **Core Worksheets:** Divided into three phases:
    *   *Foundation:* Basic exposure, highly guided, thick lines, large tracing zones.
    *   *Developing:* Moderate difficulty, reduced visual guides, independent steps.
    *   *Mastery:* Complex tasks, smaller fonts, independent problem solving.
9.  **Creative Challenge Activity:** Open-ended project or critical thinking puzzle mapping to Bloom's Taxonomy Level 5 (Evaluate) or Level 6 (Create).
10. **Cumulative Assessment:** formal evaluation page mimicking worksheet styles to test target learning outcomes.
11. **Answer Key:** Mini-thumbnails of every worksheet with correct answers highlighted in red overlay text (#E53935).
12. **Printable Certificate of Completion:** Landscape A4 sheet with ornamental border, name line, achievement text, date line, and signature lines.
13. **Student Progress Tracker:** Visual path or grid for students to cross out completed worksheets and color in 1-3 stars.
14. **Optimal Printing Guide:** Technical settings for double-sided/single-sided, margin scaling (100% border safety), and paper weight recommendations.
15. **Copyright Page:** Official legal warning, brand registration data, and intellectual property notices.
16. **License Terms:** Boundaries of Single-Classroom or Personal Use rules and instructions on purchasing school-wide extensions.
17. **Version History Log:** Table documenting Version, Date, Author, and list of Changes made.
18. **Internal Quality Sign-off:** Sign-off record containing name, date, and initials of all QA reviewers. This page is stripped from final customer files.

# 5. QUALITY ASSURANCE

Every resource must pass our multi-disciplinary QA check before release. The QA process tests educational validity, visual standards, technical performance, and commercial viability.

## 5.1 Verification Checklist

```
================================================================================
                    WORKSHEET WONDER — MASTER QA REGISTER
================================================================================
Bundle ID: ______________________             Last Updated: _______________
Lead QA Inspector: ______________             Status: [ ] Approved / [ ] Hold
================================================================================

1. EDUCATIONAL INTEGRITY CHECK
  [ ] All curriculum outcomes map to Master Curriculum (WW-MC-001).
  [ ] The learning path follows progression (Easy -> Medium -> Hard).
  [ ] Language, instructions, and complexity are age-appropriate.
  [ ] Academic vocabulary is introduced with definitions.
  [ ] Answers in the Answer Key are verified by secondary calculation.

2. SPELLING & LINGUISTIC ACCURACY
  [ ] Run spelling checks on all pages.
  [ ] Checked for consistency (e.g., US or UK English spellings).
  [ ] Active voice and present tense are used in instructions.
  [ ] All proper nouns are correctly capitalized.

3. ARTWORK & STYLE STANDARDS (WW-IB-001/002/003)
  [ ] Visual style aligns with Illustration Bibles (rounded, soft, friendly).
  [ ] Stroke weights conform to L1-L5 levels; linecaps are rounded.
  [ ] SVGs are built from clean vectors; no embedded raster images.
  [ ] All character assets maintain correct age proportions.
  [ ] No forbidden shapes, expressions, or visual clutter.

4. B&W PRINTING & TONAL CONTRAST
  [ ] Run physical print test on standard 80gsm paper.
  [ ] Tonal contrast between adjacent shapes is 30%+ grey level.
  [ ] Grey fills do not exceed 35% total page coverage (toner economy).
  [ ] No critical educational detail is lost in grayscale.

5. ACCESSIBILITY STANDARDS (WCAG 2.1 AA)
  [ ] Minimum font sizes are met (Preschool: 18pt; KG: 16pt; Grades 1+: 14pt).
  [ ] Text-to-background contrast ratio is 4.5:1+.
  [ ] Color is never the sole indicator of educational meaning.
  [ ] Nunito font family is used for body text (dyslexia friendliness).
  [ ] Writing lines, drawing zones, and buttons fit age motor skills.

6. PDF EXPORT SPECIFICATION
  [ ] Compiled PDF contains all 18 components in the exact order.
  [ ] Page size is A4; safety margins are 15mm (top/bottom) and 12mm (sides).
  [ ] All fonts are embedded; file version is PDF/A-1b.
  [ ] PDF is text-searchable (not rasterized/scanned).
  [ ] Target file size is under 25MB.

7. METADATA & SEO CHECK
  [ ] File title metadata is set correctly to match the Product Name.
  [ ] File author metadata is set to "Worksheet Wonder".
  [ ] Primary search keyword is placed in the description within first 150 chars.
  [ ] Listing title, tags (13 minimum), and price match specifications.

8. BRAND CONSISTENCY CHECK
  [ ] Official brand logo is present on Cover, Welcome, and Certificate.
  [ ] "Worksheet Wonder" copyright footer is on every worksheet page.
  [ ] Bundle ID is displayed on every page footer.
  [ ] Colors (if applicable) match the brand palette.

================================================================================
QA Deciding Notes: _____________________________________________________________
________________________________________________________________________________
```

# 6. VERSION CONTROL

Worksheet Wonder uses semantic versioning to track edits, corrections, and revisions.

## 6.1 Semantic Version Definition

```
   Version Number: v[MAJOR].[MINOR].[PATCH]
                     │       │       │
  Major Redesign ────┘       │       └──── Typo, alignment, error fixes
                             └──────────── Added worksheets or guides
```

*   **vX.Y.Z - PATCH:** Corrects typos, line alignments, spelling errors, or errata. *Example: v1.0.0 → v1.0.1.*
*   **vX.Y.0 - MINOR:** Adds new worksheets, updates illustrations, or expands teacher guides without changing the core curriculum outcomes. *Example: v1.0.0 → v1.1.0.*
*   **vX.0.0 - MAJOR:** Complete redesign of the product, major layout overhaul, or realignment to a new version of the Master Curriculum. *Example: v1.0.0 → v2.0.0.*

## 6.2 Archive Rules

*   **Retention:** All released versions must be archived as read-only PDF files in the product's `exports/pdf/archive/` folder.
*   **Archived File Format:** `[BUNDLE-ID]-COMPLETE-v[X.X]_[YYYY-MM-DD].pdf`
*   **Decommissioning:** When a major version is replaced, the old version listing is updated with a notice pointing to the new version, but the download remains available to existing buyers in their purchase history.

## 9.2 Automation SOPs


## 11.2 Platform Publishing SOPs

### 11.2.1 Teachers Pay Teachers (TPT)
1.  **Login:** Connect to the Worksheet Wonder TPT Store dashboard.
2.  **File Upload:** Upload the complete `[BUNDLE-ID]-COMPLETE-v1.0.pdf`.
3.  **Visual Assets:** Upload `[BUNDLE-ID]-THUMB-TPT.jpg` as the main thumbnail. Upload previews `[BUNDLE-ID]-PREV-01.png` to `-04.png`.
4.  **Taxonomy Details:**
    *   Set Grade Level(s) (e.g., Preschool).
    *   Set Subject Areas (e.g., Pre-Writing Skills).
    *   Set Resource Type (e.g., Worksheets, Printables).

6.  **Pricing:** Set standard price based on target per-page value.
7.  **Publish:** Click "Publish" to activate the listing.

### 11.2.2 Etsy Shop
1.  **Login:** Connect to the Worksheet Wonder Etsy Shop Manager.
2.  **Listing Type:** Create a new listing. Select "Digital File" under Type.
3.  **Visual Assets:** Upload `[BUNDLE-ID]-THUMB-ETSY.jpg` (2000x2000px). Upload remaining mockups.

    *   *Title:* Enter search-friendly title.
    *   *About:* Select "I made it", "A finished product", "Made to order".
    *   *Category:* Select "Learning & School" → "Worksheets".
5.  **Description:** Paste listing description.
6.  **File Upload:** Upload `[BUNDLE-ID]-COMPLETE-v1.0.pdf` to the digital delivery section.
7.  **Taxation & Price:** Set price and tax status.
8.  **Publish:** Click "Publish".

### 11.2.3 Amazon KDP (Workbooks)
1.  **Login:** Connect to the Worksheet Wonder KDP Bookshelf.
2.  **Format:** Select "Create Paperback".
3.  **Book Details:**
    *   *Language:* English.
    *   *Title:* Title matches standard workbook naming format.
    *   *Author:* Primary Author: "Worksheet Wonder".
    *   *Description:* Standard Amazon-friendly description.
4.  **Interior Setup:**
    *   *Ink Type:* Black & white interior with cream paper OR white paper.
    *   *Trim Size:* A4 (8.27" x 11.69").
    *   *Bleed:* Set "Bleed (PDF only)".
    *   *Cover Finish:* Matte.
5.  **File Upload:** Upload the A4 print-ready PDF interior file and the cover PDF.
6.  **Review:** Open the KDP Previewer tool to check for margin errors.
7.  **Publish:** Set pricing and submit.

# 14. MAINTENANCE & ERRATA

Post-release maintenance preserves the long-term value of our products.

## 14.1 Errata Lifecycle

```
  [Customer Reports Issue] ──► [Log in Errata Database] ──► [Assign Fix to Designer]
                                                                    │
                                                                    ▼
  [Notify Customers] ◄────── [Upload Updated PDF] ◄────────── [QA Verification]
```

## 14.2 Errata SOP

1.  **Intake:** Customer support registers a bug or typo report.
2.  **Verification:** The QA team verifies the bug against the source files.
3.  **Logging:** Record the issue in the central Errata sheet: `[Date] | [Bundle ID] | [Page Number] | [Description] | [Priority]`.
4.  **Fix:** A designer updates the source HTML/SVG files.
5.  **Verification:** The QA team checks the updated page.
6.  **Export:** Export the corrected PDF file, incrementing the version (e.g., v1.0.0 → v1.0.1).
7.  **Distribution:** Upload the updated PDF to replace the old files on TPT, Etsy, KDP, and Shopify.
8.  **Customer Notification:** Send a system notification to existing buyers letting them know an update is available to download.

# 15. FUTURE SCALING

To scale Worksheet Wonder towards 10,000+ pages, we use modular systems.

## 15.1 Internationalization (Translation) SOP

```
  [Source HTML File] ──► [Extract Text Strings] ──► [Professional Translation]
                                                            │
                                                            ▼
  [Export Translated PDF] ◄── [Inject Translated Strings] ◄─┘
```

1.  **Source Code:** Open the clean HTML source of the target bundle.
2.  **String Extraction:** Run our script to collect all user-facing text from divs, labels, and guides. Save as `[BUNDLE-ID]-source-strings.json`.
3.  **Translation:** Send the JSON file to certified translators for target locales (Spanish, French, German, Arabic).
4.  **Re-injection:** Run our injection script to merge the translated strings back into the HTML template, generating localized versions (e.g., `[BUNDLE-ID]-ES`).
5.  **Review:** Local reviewers check the translated pages for formatting or layout issues.
6.  **Export:** Compile the localized PDF.

## 15.2 Print-on-Demand (POD) Compilation
1.  **Mega-Bundles:** Combine 5–10 related individual bundles into single 200+ page workbook PDF files.
2.  **Page Numbers:** Add sequential page numbering across the compiled book.
3.  **Amazon KDP Publishing:** Publish the compiled workbook through Amazon KDP to offer customers a physical book option.
