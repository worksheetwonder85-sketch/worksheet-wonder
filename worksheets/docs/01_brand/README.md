## Scope

The Design Bible is the **root document** of the entire Worksheet Wonder documentation system. It governs:

- Brand identity and voice
- Educational philosophy and pedagogy
- Typography (Fredoka One, Nunito)
- Layout standards (A4, 40% minimum white space)
- Border system (dual-border with rounded corners)
- Line weight hierarchy
- Tracing line specifications
- Colour and B&W printing standards
- Accessibility (dyslexia, ADHD, autism considerations)
- Commercial publishing standards (TPT, Etsy, KDP, SEO)
- Licensing and copyright

All other documents in this library inherit from and must not contradict this document.
