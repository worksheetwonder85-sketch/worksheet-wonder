# 07_Archive — Archived Document Versions

```
Section:       07_Archive
Maintained by: Documentation Coordinator
Last Updated:  09 July 2026
```

This section stores superseded versions of all Worksheet Wonder documentation.

---

## Archive Policy

When a document is updated to a new version:

1. **Rename** the superseded version with a date suffix:
   ```
   WW-DESIGN-BIBLE_v1.0_2026-07-09.md
   ```

2. **Move** it to this `07_Archive/` folder

3. **Place** the new version in its original section folder

4. **Update** the master `docs/README.md` Document Registry

5. **Log** the change in the document's Version History section

6. **Notify** all team members

---

## Naming Convention for Archived Files

```
[ORIGINAL-FILENAME]_v[VERSION]_[YYYY-MM-DD].md

Examples:
  WW-DESIGN-BIBLE_v1.0_2026-07-09.md
  WW-MASTER-CURRICULUM_v1.0_2026-07-09.md
  WW-ILLUSTRATION-BIBLE-PART-1_v1.0_2026-07-09.md
```
